In this project, my teammates and I analyzed The National Weather Association Storm Events dataset and tried to predict the property damage caused by tornados. Using stepwise regression and the log of a linear model our model was able to explain almost half the variance in property damage using statistics like wind speed, tornado size, rough location and others. Given more in depth statistics like population density and the average age of buildings in the county our model could have been accurate.
